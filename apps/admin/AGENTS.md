# 管理后台协作规则

本目录继承仓库根目录 `AGENTS.md`，并补充 Web 管理后台约束。

## 技术与组织

- 使用 Vue 3、TypeScript、Vite、Vue Router、Pinia 和 Element Plus。
- 业务代码按 `src/modules/<domain>` 组织；跨模块通用布局、基础组件和基础设施分别进入 `layouts`、`components` 和 `services`。
- 页面和组件不直接拼接数据库概念或请求细节，统一通过服务层及 `packages/api-client` 访问 API。
- 全局 store 只保存会话、权限快照和真正跨路由的状态，页面局部状态留在页面或 composable 中。

## 权限与数据

- 路由守卫、菜单和按钮显隐只改善体验，不能替代 API 鉴权。
- 登录失效、403、业务冲突和系统错误使用统一处理入口，同时保留用户可理解的上下文。
- 表格、导出和详情接口只请求当前角色有权查看的字段，避免先取全量敏感数据再由前端隐藏。
- Mock 数据和真实接口必须有明确边界，不得在验收结果中混用。

## 验证

- 依赖可用时，运行 `pnpm --filter @huiju/admin type-check`、相关测试和必要构建。
- 关键管理操作至少覆盖：无权限、空数据、请求失败、重复提交和成功反馈。
- 静态检查、浏览器本地验收、真实 API 验收和部署环境验收分别记录，不相互替代。
