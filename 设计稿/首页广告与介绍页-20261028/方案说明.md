## 初次确认范围（高度已由上段替代）

- 活动、助手首页：3:1矮轮播；学友圈：2:1高轮播；我的：2:1高背景。
- 后台管理员维护广告及介绍内容；上传显示尺寸比例、支持裁剪。
- 轮播广告点击进入关联的项目/公司介绍，含企业名称、联系人、联系方式和介绍图文。
- 广告数量不设业务总量上限。不做用户申请、上传审批、智米计费；不混入第25项活动详情最多3张/5:4规则。

## 已确认实施方案（保留原建议表述供追溯）

1. **我的背景不点击跳转**：仅一张背景，由后台更换，保留头像、用户名、资料入口。若希望也承担广告用途，需要另行明确点击区域，避免与资料入口冲突。
2. **广告与介绍分开维护**：一个介绍内容可被多个广告引用；同一广告可投放活动/学友圈/助手，按3:1和2:1分别存图。活动和助手可共用同一3:1结果。介绍封面另用2:1，详情图片完整展示、不强制裁剪。
3. **后台管理**：新建默认为草稿，保存→预览→确认上架；支持已上架/已下架/草稿筛选、位置筛选、搜索与分页（建议20条/页）。排序值越小越靠前，同值以创建时间和ID稳定排序；先做上下架，不加删除与排期。编辑已上架内容提示即时影响范围；多人修改冲突保留输入、提示重新加载。
4. **轮播展示**：建议5秒自动轮换并支持手动滑动，离页暂停；1张不自动轮播也不显示页码，0张沿用当前品牌图且不跳转。只展示有效已上架内容；不把不限数量实现为一次下载全部图片：服务端分页、小程序接近尾部预加载下一批，最后一页后回到首批，失败保留当前图片可重试。显示当前位置/总数。后台与轮播都不默默只取前N条。
5. **介绍页**：名称、企业名称、联系人、电话或微信至少一项、介绍内容为必要内容；简介可选。实际表单中项目名/企业名分别保存（设计稿合并一行示意）。电话按钮询问后调用系统拨号，微信可复制；无电话时仅保留复制操作。内容只读展示建议沿用游客可浏览规则，联系人为管理员明确公开的商务信息，不读取会员私人资料。
6. **权限**：建议超级管理员及具有内容维护权限的普通运营可维护；普通会员不能操作。需核对现有权限模型后明确映射，不默认所有后台账号都有发布权限。所有写入由服务端鉴权、校验并记录操作者。
7. **素材**：建议输出3:1为1500×500、2:1为1500×750；比例强制，像素为建议清晰度。PNG/JPG格式，建议单文件不超过5MB；不足建议像素提示清晰度，不无意义拉伸。广告文案如已在图片中排好，前端不再叠同样标题；本稿图片上标题示意最终广告成图，非新增强制文字字段。

## 页面与实现边界

现状核对：活动/助手已有静态图片和运营文案；我的已有背景与资料叠加；学友圈已有首页结构。后台App菜单和ContentPage维护运营文案，未找到广告管理模块。新增广告管理与图文介绍链路需要接口、图片存储和数据库设计；本轮未编写这些业务代码。

建议小程序新增介绍路由（名称待实施定稿），只传介绍ID，不传联系方式。后台新增首页广告入口，内含轮播列表、背景设置、广告编辑及介绍编辑；原有运营文案入口保留。现有首页下方内容、原生导航、TabBar和两个助手能力保持；效果稿下方内容仅为布局参照，不构成重做指令。

建议数据划分：介绍内容（名称、企业、联系人、公开联系字段、封面、图文）；广告（介绍引用、位置、两种裁剪资源、排序、状态）；个人中心背景配置。接口候选包括公开广告分页/介绍读取，后台CRUD中的创建更新查询/上下架及图片上传。具体迁移和权限契约另行审核；本轮不执行迁移。

## 状态与操作约定

| 场景 | 方案 |
| --- | --- |
| 首页加载/无广告/接口失败 | 同比例品牌底图保持高度，业务列表可继续使用；失败提供低干扰重试，不把失败当无广告 |
| 介绍加载 | 骨架屏；失败可重试；下架或不存在显示“该介绍暂不可查看”，不返回失效联系方式 |
| 介绍被多处引用 | 编辑保存提示受影响广告；下架介绍同时阻止关联广告展示，上架广告必须校验介绍可用 |
| 后台空列表/无匹配 | 区分“暂无广告，创建第一条”与“无匹配结果，清除筛选” |
| 上传/裁剪 | 上传中禁用提交；失败可重选；取消不覆盖旧图；跨比例各自确认；保留源图用于重新裁剪 |
| 保存/上架 | 校验定位具体字段；提交锁；成功提示并刷新；失败保留输入；离开未保存页面提示 |
| 无权限/会话过期 | 禁止写入，提示权限或重新登录，不能仅隐藏按钮 |
