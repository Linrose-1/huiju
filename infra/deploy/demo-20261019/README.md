## 命令

在仓库根目录执行。仅使用已有Node 24、API依赖和构建产物，不安装新依赖。默认计划可在本机执行：

```bash
node infra/deploy/demo-20261019/import.mjs
node --test infra/deploy/demo-20261019/import.test.mjs
```

服务器将下列占位符替换为**只读核对所得**的实际值，先确保备份与回执父目录由huiju可访问且不在公开Web目录。备份文件应对huiju只读、其余用户不可读；执行用户huiju以确保媒体对API可读：

```bash
sudo -u huiju env PATH=/opt/node24/bin:/usr/bin:/bin \
  node --env-file=/etc/huiju/api.env infra/deploy/demo-20261019/import.mjs \
  --rehearse --database-target=127.0.0.1:3306/huiju \
  --member-id=<真实会员UUID> --member-number=<真实会员编号> \
  --base-date=<北京时间导入日期YYYY-MM-DD> \
  --backup-file=<仓库外已校验备份绝对路径> \
  --receipt-file=<仓库外本次演练回执绝对路径>
```

演练通过后，将 `--rehearse` 换为 `--apply`，并换一个全新回执文件名。脚本拒绝不匹配的库、入口、服务用户和资料不全账号，备份须为两小时内。回执使用独占创建，防止覆盖上次证据。

默认只计划，不自动读取本机 `.env`。显式服务器模式才访问数据库；脚本没有用户表UPDATE、注册身份、协议同意或任何热度数据写入口。数据库与媒体回滚只能覆盖本次未提交写入；已尝试commit后结果未知时保留媒体供核对。维护导入以用户明确授权标注发布记录，不调用模拟登录。
