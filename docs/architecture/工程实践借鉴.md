### 适配边界

- 工坊 `packages/contracts` 当前只有规则，未发现完整生成实现；会聚契约检查基于自身已有 OpenAPI 工具实现，不宣称复制了工坊成熟脚本。
- 猩商态 Harness 有完整范围选择与执行，会聚只保留当前需要的计划模式；不引入 Python 检查系统、强制日志差异门禁或复杂自动路由。
- 两项目的运行端口、数据库账号、服务器地址、视觉尺寸、业务规则和历史“通过”状态均不迁入。源文档与实现不一致时，记录差异，不能把旧结论当成会聚事实。
- 不采用基于 ID 形状自动切 Mock 的历史实现。Mock 与真实 API 必须显式说明，不能用静态画面充当业务联调。
- 不引入 PostgreSQL/Prisma、Flask/SQLAlchemy、Outbox、微服务、积分账、支付、冻结 AI 或统一软删除；这些不属于当前需求。
- 认证环境隔离、迟到请求防护、微信传输适配随登录切片实现；当前仅落成约束和验收条件，不预建完整认证框架。
- 目前不新增 CI 部署或自动数据库任务。`verify` 可供将来 CI 复用，仓库外运行、安装、迁移和部署仍需各自环境准备与授权。
