## 用户链路与边界

会员主动提交聚会想法后，助手以结构化候选为起点，用问答卡补齐缺项。模型从仍需澄清的字段中选择下一问，同时生成问法和建议。用户选定或写下答案后，助手结合已确认安排继续对话。确定性校验仍用于判断缺项、检查时间与金额，以及判断能否发布。用户在邀请预览中核对内容，可打开完整活动编辑页，最终沿用活动创建、发布接口与服务端校验。对话生成本身不创建活动。

可草拟的字段为标题、介绍；可从明确文字提取的字段为开始/结束时间、地点、人数上限、免费/收费及固定金额、报名截止时间、报名问题。封面与咨询联系方式留给用户填写。无法确定的字段保持待填写；尤其不能把编辑页当前的默认“免费”误当成 AI 已判断的费用，也不能把相对日期猜成确定日期。报名问题的题干可生成，题型、必填与选项无明确依据时交给用户核对。编辑页继续执行原有必填、时间顺序、金额与报名问题校验。

## API 与模型调用

- 小程序只请求有聚点 API；API 校验会员会话及资料完整度后，调用 `ai` 模块的 provider 适配层。有聚点独立配置 AgentIsHere / `gpt-5.6-sol`，不依赖猩球工坊的账号、业务数据或计费记录。密钥只存放在后端本地环境，不进入小程序、仓库或日志。
- 首次请求发送用户主动提交的活动想法；对话请求可附带已确认的聚会字段、近期相关问答以及待澄清字段。咨询联系方式在客户端单独填写。API 不附加会员资料或邀请关系。模型返回的结构化候选经服务端校验后才能进入聚会草稿。
- 服务端校验模型提取的日期。问答卡使用北京时间解释有明确参照的日期，单独的“下午”不能确定开始和结束时刻。用户可点选具体时间或自填，预览以最终选择为准。
- 2026-10-02 字段校验补强：只有年份或年月不能放行模型给出的完整日期。原文明确写明时间、人数、费用等“待定／未确定／待确认”时，对应候选置空并进入待填写项；开始、结束、报名截止及收费模式、金额分别处理，保留独立明确的信息。这是针对明确待定表述的有限规则，不是对任意自然语言或全部模型事实的完整核验；候选仍需发起人检查确认。
- 返回候选字段和待填写项。小程序按会员和环境保留本机对话草稿，重新进入时由用户决定是否恢复；进入完整编辑页时传递当前候选和已确认的联系方式。
- 首次生成与后续追问不限制每日次数。服务端保留会员唯一的短期请求预留；模型调用位于事务外，完成或失败时仅释放本次预留。预留 120 秒后可替换，模型超时 90 秒，单个 API 进程最多同时处理 4 个生成请求。
- 调用设置超时和单次请求边界；失败向客户端返回稳定、安全的错误码及重试提示，不透出供应商响应或密钥，不自动重试或切换供应商。用户保留输入，可自行再次点击生成；重复点击期间禁用提交。
