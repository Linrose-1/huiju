# 会聚｜AI 活动草拟技术设计

状态：方案已确认；截至 2026-09-30，代码、本机迁移、真实模型调用及微信开发者工具模拟身份回填链路已完成，真实微信身份、真机与真实数据库并发限额未验收。依据[首期 PRD F07](../product/首期PRD.md)与[小程序框架与导航](../product/小程序框架与导航.md)。本文只覆盖“帮我发活动”；“帮我找活动”另行设计。

## 用户链路与边界

助手入口展示想法输入界面。用户输入一段普通文字并主动点击“生成草稿”；系统输入法的语音输入与键盘输入等价，项目不接入录音和语音转写。生成成功后把结构化候选字段带到现有 `pages/activity/editor`，直接进入编辑流程。生成动作不调用创建活动或发布接口；只有用户在编辑页主动保存、确认发布时，才沿用现有活动写入与校验流程。

可草拟的字段为标题、介绍；可从明确文字提取的字段为开始/结束时间、地点、人数上限、免费/收费及固定金额、报名截止时间、报名问题。封面与咨询联系方式留给用户填写。无法确定的字段保持待填写；尤其不能把编辑页当前的默认“免费”误当成 AI 已判断的费用，也不能把相对日期猜成确定日期。报名问题的题干可生成，题型、必填与选项无明确依据时交给用户核对。编辑页继续执行原有必填、时间顺序、金额与报名问题校验。

## API 与模型调用

- 小程序只请求会聚 API；API 校验会员会话及资料完整度后，调用 `ai` 模块的 provider 适配层。会聚独立配置 AgentIsHere / `gpt-5.5`，不依赖猩球工坊的账号、业务数据或计费记录。密钥只存放在后端本地环境，不进入小程序、仓库或日志。
- 请求只含用户主动提交的活动想法；API 不附加手机号、真实姓名、邮箱、邀请关系或其他会员资料。输入页提示用户避免填写无关的敏感身份信息。模型仅返回结构化候选，服务端检查类型、长度、枚举、数值和时间关系；不能验证或含糊的值返回空，不能把模型原始文本直接当作活动写入数据。
- 模型遗漏或返回不合格式的日期时，解析器仅对原文中的完整中文年月日和无歧义时刻作确定性补全；相对日期、缺少年份或含糊时间仍保持空。仅日期补全不能使空模型回复成为有效草稿。
- 返回候选字段和剩余待填写项，客户端把它们映射到编辑页。接口、DTO、OpenAPI 与生成客户端在实现时同步定义；现有活动创建、修改、发布接口的权限与校验保持原规则。
- 限额按会员和北京时间自然日计算，最多 5 次有效结构化草稿返回；失败不计次。服务端以最小记录保存会员标识、生成时间和成功状态，不保存输入全文或模型原始回复。并发请求必须在服务端保证不会突破成功次数上限。
- 调用设置超时和单次请求边界；失败向客户端返回稳定、安全的错误码及重试提示，不透出供应商响应或密钥，不自动重试或切换供应商。用户保留输入，可自行再次点击生成；重复点击期间禁用提交。

## 实现与验收口径

实现映射（截至 2026-09-30）：助手卡片进入 `pages/assistant/activity-draft`，生成成功后用仅存内存、绑定会员与会话代次的候选数据进入 `pages/activity/editor`。后端 `POST /api/v1/ai/activity-drafts` 已接入模型适配层、资料门槛与成功次数记录；编辑页对 AI 未判定的费用保持未选择，保存前要求会员确认。服务端在会员行锁事务中检查次数并记录成功结果，失败回滚；真实数据库并发限额仍需单独验收。

2026-09-29 已获授权在 `127.0.0.1:3306/huiju` 应用 `0006` 并核对迁移记录、表结构与索引；配置后端模型后完成真实 AgentIsHere 调用。微信开发者工具通过模拟会员输入生成并回填标题、介绍、时间、地点、人数、收费金额与报名问题；明确日期兜底修正后已再次真实生成验证。生成成功记录增加，测试活动未保存或发布。此证据覆盖本机 API/数据库、外部模型及模拟器表单承接，不代表真实微信授权、真机或部署通过，详见[当月实现日志](../implementation-log/2026-09.md)。
