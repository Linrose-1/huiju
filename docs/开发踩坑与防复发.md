## 已验证经验

## Corepack 不接受 SOCKS5 代理地址

- 日期：2026-09-25。
- 影响范围：使用 Corepack 下载或调用项目声明的 pnpm 版本。
- 症状：`corepack pnpm --version` 在下载前报 `Invalid URL protocol`，要求 URL 使用 `http:` 或 `https:`。
- 根因：当前进程的 `HTTP_PROXY` 和 `HTTPS_PROXY` 使用 `socks5://`，Corepack 所用网络库不接受该代理协议。
- 修复：只在当前 PowerShell 进程中清空 HTTP、HTTPS、ALL_PROXY 的大小写变量，并设置 `COREPACK_NPM_REGISTRY` 为当前可直连的 npm registry，再运行 Corepack；不改写系统代理。
- 验证：Corepack 成功下载并运行 pnpm `12.6.0`，workspace 安装完成，锁文件生成，后续 type-check 和 build 通过。
- 防复发：项目安装命令优先使用 Corepack；再次出现相同错误时先检查代理协议，不要重复删除缓存或改依赖版本。
- 相关文件或命令：根 `package.json` 的 `packageManager`、`pnpm-lock.yaml`、`corepack pnpm install`。

## 列表能滚动不代表能加载后续数据

- 日期：2026-09-29。
- 影响范围：小程序活动列表；同类可能增长的列表可按此检查。
- 症状：页面支持下拉刷新和滚动，但滑到底部不会继续请求；公开活动接口一次最多返回 100 条，更多活动无法从列表进入。原搜索和“即将开始”只筛选当前已取回的项目，结果可能不完整。
- 根因：活动页只有 `onPullDownRefresh`，没有触底回调和追加状态；`GET /activities` 固定 `.limit(100)`，没有页码、`hasMore` 或服务端筛选。
- 修复：接口按每页 10 条提供 `offset`、排序、搜索和 `hasMore`；页面触底追加，下拉刷新、搜索及筛选变化时从第一页重取，并区分首次加载、追加加载、没有更多和失败重试。追加失败保留已显示卡片，避免重复请求和迟到响应覆盖。
- 验证：本地测试库 17 条公开活动由 API 分为 10＋7 条，下一页为空，前两页 ID 无重复；小程序与 API 聚焦及常规工程检查通过。用户随后反馈“可以了”，确认本轮活动列表效果可接受；断网重试和真机仍未单独验收。
- 防复发：新增或改造列表时先查数据是否可能超过接口上限，再同时设计服务端分页、完整数据范围内的搜索／筛选和页面的加载／无更多／失败重试；用超过一页的数据验收触底追加和末页。通用约束见根 `AGENTS.md`，小程序细则见 `apps/miniapp/AGENTS.md`；规则不等于其余现有列表已改造。
- 相关文件或命令：`apps/miniapp/src/pages/activity/index.vue`、`apps/api/src/flow/activity.ts`、`docs/api/README.md`；`GET /api/v1/activities?offset=0` 与 `?offset=10`。

## 个人资料网络失败先核对 API 与编译模式

- 日期：2026-09-30。
- 影响范围：本地微信开发者工具中的个人资料及其他真实 API 页面。
- 症状：页面提示“网络连接失败”，Network 的 `session`、`profile-details` 请求失败。
- 根因：本次 3000/3001 均无监听，3001 健康请求被拒绝；当前小程序开发产物指向 3001 local-test API，后端进程未运行。
- 修复：核对本机测试数据库与编译目标后，用 `corepack pnpm dev:api:local-test` 启动回环 3001 API，健康返回 200；微信工具点击重新加载，资料请求成功并显示原资料。
- 验证：2026-09-30 服务恢复、页面重试通过；后续真实本地资料保存、名片预览与设置链路通过，详见当月实现日志。
- 防复发：先看实际请求地址，再查对应端口监听及健康状态；同时核对开发产物 `LOCAL_TEST` 与 API 地址。仅保留一个小程序开发编译进程，避免 HBuilderX 普通模式和 local-test watch 互相覆盖。不要因后端未运行而绕过鉴权或重写页面。
- 相关入口：`scripts/README.md`、`apps/miniapp/src/services/api/environment.ts`、`HANDOFF.md`。端口与进程均为易变事实，每次接续重新核对。
