# 实现日志说明

实现日志按月记录已经完成且有证据的工程事实，帮助后续人员快速找到“什么时候改了什么、验证到哪一层”。

## 记录规则

- 文件名使用 `YYYY-MM.md`。
- 只记录已发生的实现和真实验证，不把计划、愿望或推测写成完成事实。
- 每条包含日期、范围、改动、验证和未验证项。
- 产品规则写入 `docs/product`，架构决策写入 `docs/adr`，当前状态写入根 `HANDOFF.md`。
- 后续修正旧结论时新增更正记录，不悄悄改写历史证据。

## 条目模板

```md
## YYYY-MM-DD｜标题

- 范围：
- 改动：
- 验证：
- 未验证：
- 关联文档：
```
