# 验证与验收

先按本次文件和风险选择检查。以下命令在仓库根目录执行，使用已安装依赖；不自动安装或升级。`corepack pnpm verify:plan <文件...>` 只列建议，不执行检查、不读取 `.env`，也不会自动选中其他未提交文件。

## 最小验证矩阵

| 改动 | 推荐检查 | 不能据此证明 |
| --- | --- | --- |
| 纯文档、规则 | 引用路径与事实核对、`git diff --check` | 实现、接口、部署已完成 |
| 小程序页面 | `corepack pnpm --filter @huiju/miniapp type-check`、`build`；TS/Vue 改动运行根 `lint` | 微信能力、真机视觉与返回路径 |
| 后台页面 | `corepack pnpm --filter @huiju/admin test`、`build`（已含类型检查）；代码改动运行根 `lint` | 空测试套件不代表业务通过；仍需浏览器验收 |
| API | `corepack pnpm --filter @huiju/api type-check`、`test`；代码改动运行根 `lint` | 仓储替身或健康 HTTP 不证明身份、权限、并发或数据库 |
| 路由、响应 DTO、客户端 | 上项相关检查及 `corepack pnpm api:check`（包含 API 构建） | 生成类型不证明微信传输适配可用 |
| schema、迁移 | API 检查、`corepack pnpm --filter @huiju/api db:check`；授权环境上的真实约束与事务验收 | SQL 静态检查不等于已执行迁移 |
| 工程脚本 | `corepack pnpm test:scripts`、根 `lint`，核对有效与失败输入 | 模拟文件测试不代替脚本实际运行 |
| 跨端配置、共享依赖 | `corepack pnpm verify` | 不覆盖真机、第三方、生产 |

表中的 `build`、`test` 简写沿用该行同一个 `--filter`。完整 `verify` 已包含 lint、类型检查、脚本与应用测试、构建、迁移静态检查和契约比较；通过后不重复运行相同检查。局部改动优先相关检查，不为纯文档修改全量构建。

## 命令副作用

- `verify:plan`：仅根据传入路径输出建议；不证明路径有 Git 差异、不自动发现遗漏，未识别路径返回非零以提醒人工补充。先检查 Git 状态，明确哪些文件属于本次任务。输入路径用于选择检查类别，实际命令可能扫描整个模块或仓库，不能视为逐文件隔离；区分其他脏文件引起的既有失败。
- `lint`、`type-check`、`db:check`：静态检查，不迁移数据库；未使用自动修复。
- `test:scripts`：在系统临时目录构造测试文件并清理，不覆盖仓库产物。
- 普通 API `test`：当前包含短暂监听回环端口的健康 HTTP 测试和模拟/静态测试；不加载根 `.env`，不写开发数据库。
- `build`：生成或更新 `dist`。`api:check` 先构建 API，再组装 Nest 应用导出临时契约（不监听端口），比较后清理临时文件；不覆写正式 OpenAPI 和客户端。
- `api:generate`：主动改写 `docs/api/openapi.json` 与 `packages/api-client/src/generated.ts`，执行后审阅差异。
- `dev:*`、`db:migrate`、外部调用：启动服务、写库或访问外部系统，独立于上述检查，仍按任务授权执行。未来 API 模块初始化不得隐藏建表、迁移或创建账号副作用。

## 首个业务闭环的验收清单

以下为待实现能力的验收要求，不代表当前已经通过：

- 清缓存冷启动可匿名浏览公开活动；微信识别失败不阻断公开浏览。
- 分享直达活动，首次有效邀请固定，重复访问不覆盖。
- 资料不足不能发布或报名，补齐后返回原操作；服务端直接请求同样执行门槛。
- 会话过期、退出、切换 API 环境或账号后，旧缓存和迟到请求不能恢复旧身份。
- 重复提交不重复报名；两人争抢最后名额只有一人成功；取消后释放一次，重新报名重新竞争。
- 普通用户只取得允许字段，发起人与管理员按各自边界访问；不能仅用按钮显隐验收权限。
- 原生导航标题由 `pages.json` 提供；清缓存、分享进入、返回刷新、弱网、加载、空与失败状态分别验证。

真实数据库验证必须显式启用并核对 host、port、database、版本和迁移状态；仅展示非敏感目标信息，不输出连接串或密码。普通测试不得自动落到开发库。使用隔离库或已授权事务回滚测试，并核对前后记录数量。MySQL DDL 不能假定可整体回滚；迁移需单独授权，禁止将旧的迁移许可扩大到其他环境。

验收记录最少包含：日期、范围、命令或操作、环境（不含密钥）、结果、证据层级及未验证项。复用同一条实现日志或 HANDOFF 索引，不另建平行状态台账。L0 静态、L1 工程、L2 本地集成、L3 微信/外部/部署分别记录。
