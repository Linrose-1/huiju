状态：2026-11-18 确认界面与首期范围。仅交付有聚点管理后台的接入配置与变更记录。

本机验收（2026-11-18）：`0027_platform_mcp_settings` 已在本机测试库应用。真实超管会话验证通过：新增对接方、分别保存搜索与详情权限、刷新回读、查看三条前后值审计。总开关保持关闭；尚未部署。详见[本机验收记录](../implementation-log/2026-11.md#2026-11-18-mcp-本地超管浏览器验收)。

## 当前阶段

- 仅超级管理员可查看和维护配置。页面显示「待接入」，总开关默认关闭；本期服务端没有开启接口，不监听 MCP 调用，不发放凭据。
- 可新增对接方、保存名称和备注、标记启用或停用。新建默认停用、无权限，不预置学加记录；对接方启用是配置状态，不代表接入已经生效。
- 后续才讨论是否正式连接学加、父子程序互通或一键发布。这些能力不属于本期；数据仍各自独立。

## 权限

| 能力 | 基础字段 | 可选字段 |
| --- | --- | --- |
| 搜索公开活动 | 活动标识、标题、时间、公开状态 | 地点、费用、封面、公开介绍 |
| 查看公开活动详情 | 活动标识、标题、时间、公开状态 | 地点、费用、封面、公开介绍 |

两项能力各自启用、各自选字段。基础字段固定，启用能力时才适用；可选字段默认全不选。停止某项能力时清空其可选字段。后台预览只说明配置效果，不调用真实活动接口。

供将来的外部工具接入遵守：未勾选字段既不返回，也不能作为筛选、排序或命中条件。未开放介绍时，关键词只匹配标题；地点、费用勾选后才支持对应筛选；封面只用于展示。会员资料、咨询联系方式、报名名单与答案不在配置范围内。将来启用前，还需要接入方鉴权及在实际调用时复查总开关、对接方、能力和字段权限。

## 验收

1. 超管可进入页面，普通运营无法通过菜单、直接路由或调用 API 查看及写入。总开关始终关闭，未启用外部路由。
2. 新增后为停用且无授权；分别修改搜索及详情的字段，互不影响，刷新仍能读取已保存配置。无权限字段、重复字段及额外属性被接口拒绝。
3. 配置预览与勾选一致。例如仅开放搜索和地点时，显示可按地点筛选并可返回地点，但不可按费用筛选、不可返回费用、不可查询详情。提交时由服务端校验字段白名单。
4. 已成功变更的配置与审计在同一事务保存。日志按时间分页，可核对操作人及前后值；取消、提交失败、版本冲突不覆盖既有配置，不产生成功日志。
5. 不连接学加，不访问或交换真实业务数据，不影响有聚点现有活动或小程序功能。待正式接入时，另验真实请求的字段筛选与返回约束。
