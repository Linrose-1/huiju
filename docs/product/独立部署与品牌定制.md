# 独立部署与品牌定制

2026-11-18 已完成首期配置及本机验收。不同公司的实际部署分别验收。

## 公司实例

各公司使用同一套代码，分别构建自己的微信小程序，并使用独立的 AppID、API、管理后台、数据库账号与库、媒体目录和备份。部署地址及微信凭据由部署者设置，与运营品牌配置分离。公司实例之间不共享账号或业务数据。

## 品牌设置

- 仅超级管理员可在现有「品牌设置」配置应用内名称、展示开关、Logo、四个 Tab 名称及合作小程序。微信平台登记名称和头像由公司在自己的微信公众平台维护。
- 配置的名称和 Logo 用于后台登录页和顶部；小程序「我世界」仅在启用品牌展示且有自定义名称或 Logo 可显示时展示品牌区。分享海报继续读取品牌名称和显示开关。关闭品牌展示不影响 Tab 名称和合作小程序入口。
- 四个导航键依次为圈子、活动、助手、个人。文字自定义，页头名称跟随，图标、顺序、路由和已有功能保持不变。空名称回退为「商友圈／友聚会／i 助手／我世界」；读取配置失败不影响基本导航。
- 保存需要当前版本。发生冲突时保留当前编辑内容并提示重新读取，成功保存记录前后值。

## 合作小程序

- 「我世界 → 我的邀请码」下方展示「合作小程序」，只有至少一项启用并配置码图时显示。
- 每项可设名称、简介、可选 Logo、小程序码图片、排序和显示开关。新项默认隐藏。上传有效码图后，打开「显示」并保存才会发布。同排序值时按保存顺序展示。
- 展示页只展示启用项，码按原图比例显示，支持原生图片放大；不裁剪、不自动识别、不直接跳转。后台仅接收 PNG 或 JPG，2 MB 以内，长宽最多 4096 像素；后台负责上传真实有效的码图并自行确认目标。未启用或未引用的图片只可由超管预览。
- 猩聚社作为首个运营配置项，由运营上传真实码；系统不内置示意码。展示码不涉及登录、账号绑定或业务数据互通。

## 验收

1. 超管保存品牌名称、Logo 与四个 Tab 名称，刷新回读；非超管不能写，过期版本不能覆盖新配置。
2. 小程序四个 Tab 及对应页头更新文字，图标、顺序和跳转维持原样。
3. 无启用项时不显示入口；启用合作项后从「我的邀请码」下方进入，能放大原图。关闭最后一个合作项后入口消失，关闭项的码图不再通过公开接口提供。
4. 另用两个独立部署验证 AppID、接口、品牌与账号数据互不影响。微信真机另验码图展示、放大与识别效果。

用户已在本机微信开发者工具确认猩聚社正式码可以显示和放大。真机识码及两套独立部署待验。参见[本机验收记录](../implementation-log/2026-11.md#2026-11-18-猩聚社合作码与默认品牌行复验)。
