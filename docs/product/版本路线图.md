# 会聚｜版本路线图

状态：产品方向记录  
日期：2026-09-24

本文件记录首期以后的版本方向，不纳入[首期 PRD](首期PRD.md)验收。各版本的详细交互、权限、数据与权益规则需在对应版本启动时再定义。

## 首期

- 活动报名与会员管理；活动有免费和收费两种模式，平台内不收款。
- 面向当前客户“学加”的活动页、助手页运营文案可由后台维护；后台指定的平台管理员也可在小程序前端修改。

## 1.5 版本：学友圈

- 园区资源：出租、出售、转让、寻租、购买。
- 运营资源、服务资源、门店。
- 上述内容均可发帖并对外分享，用于纳新与招募新学友。

## 2.0 版本：店友圈

- 以园区店为主，支持好品分享和商城分享。
- 店主上传产品，用户分享产品可获得贡献值；贡献值对店主与用户本人可视化。
- 围绕门店与平台权益进行“智米”分配。

## 后续设计待定

- 1.5：帖子审核与展示范围、分享落地与新学友加入规则、各类资源字段。
- 2.0：商城交易边界、贡献值计算、权益与“智米”分配及记录规则。

以上待定项仅提示后续设计范围，不代表已确定实现方式。
